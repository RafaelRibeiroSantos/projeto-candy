## 🎯 Sobre

Uma plataforma de e-commerce de doces desenvolvida com **HTML5, CSS3 (Tailwind) e JavaScript puro**. Oferece uma experiência intuitiva com visualização de produtos, carrinho funcional e modal de detalhes.

## ✨ Funcionalidades

- 🛍️ **Catálogo de produtos** - Vários doces com imagens e preços
- 🛒 **Carrinho funcional** - Adicionar/remover produtos, quantidade
- 🖼️ **Modal de detalhes** - Visualizar informações completas do produto
- 💰 **Cálculo de valores** - Total do carrinho atualizado em tempo real
- 📱 **Design responsivo** - Funciona em mobile, tablet e desktop
- ⚡ **Interface moderna** - Tailwind CSS para estilo profissional

## 🛠️ Tecnologias

- **HTML5** - Estrutura semântica
- **Tailwind CSS** - Estilização utility-first
- **JavaScript puro** - Lógica interativa
- **npm/yarn** - Gerenciamento de dependências

## 📦 Como Usar

1. Clone o repositório:
```bash
git clone https://github.com/RafaelRibeiroSantos/projeto-candy.git
cd projeto-candy
```

2. Instale as dependências:
```bash
npm install
```

3. Abra `index.html` no navegador ou use live server

4. Navegue pelos doces, adicione ao carrinho e veja a mágica!

## 💡 O que Aprendi

- Manipulação avançada do DOM
- Eventos de clique e interatividade
- Gerenciamento de estado (carrinho)
- Tailwind CSS para styling eficiente
- Data attributes para rastreamento de dados
- Modais e transições CSS
